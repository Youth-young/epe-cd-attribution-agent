# 데이터의 근거

## 이 데이터는 합성이다
실제 fab 데이터가 아니다. 계측 정합성 실습(3-way CD split)에서 직접 구한 회귀 결과를
앵커로 삼고, 현업 계측 구조를 본떠 성분 합으로 생성했다.

## 실습에서 그대로 가져온 값 (measured)
| 항목 | 값 |
|---|---|
| ADI CD Target | 130 nm |
| ACI CD Target | 110 nm |
| 단면(VSEM) BCD Target | 90 nm |
| etch bias (ACI − ADI) | −20 nm |
| ADI→VSEM 회귀 | 기울기 1.0, 절편 −40 nm |
| ACI→VSEM 회귀 | 기울기 1.0, 절편 −20 nm |

실습 표에서 BCD 조건은 ADI 140/148/125 → ACI 120/128/105 → VSEM 100/108/85 이며,
세 단계의 차이가 각각 정확히 20 nm와 20 nm로 유지된다. 목표 BCD 90 nm를 대입해 얻은
ADI 130 / ACI 110 이 이 데이터셋의 중심값이다.

## 문헌 통상 범위에서 취한 값 (literature)
웨이퍼 내 CDU 3σ, dose sensitivity, Bossung 곡률, CD-SEM precision, 확률 성분 σ.
정확한 출처가 있는 값이 아니라 해당 세대 공정에서 통용되는 크기 순서다.

## 근거 없는 가정 (assumed)
슬릿 지문 진폭, 레티클 σ, 챔버별 반경 계수, PM drift 기울기, 프로파일 taper 10 nm,
taper가 etch bias 변화를 따라가는 비율.

**taper는 실습 데이터에 없다.** 단면 프로파일을 식각 원인과 계측 원인을 가르는 보조
증거로 쓰기 위해 추가한 가정이며, 크기만 물리적으로 타당하게 잡았다.

## 현업 구조를 반영한 부분
- 웨이퍼 전면 CD 맵은 존재하지 않는다. 9 field × 5 site = 41점 샘플링
- ADI는 로트당 3장(slot 3/13/23), ACI는 로트의 절반만 1장
- 단면 측정은 파괴적이므로 주 3회 5점
- 계측 장비 drift는 golden wafer 재측정으로 감시
- ADI와 ACI는 동일 좌표를 공유한다 (정합성 확보를 위한 실제 recipe 관행)

## 가장 확신이 없는 것
주입 신호의 크기다. 크게 넣으면 판정이 쉬워져 의미가 없고, 작게 넣으면 검증이
불안정해진다. 현업 담당자의 검토를 받지 못한 상태다.
