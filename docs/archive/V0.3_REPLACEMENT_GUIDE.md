## 3. Agent 도구를 CLI에서 먼저 확인

```bash
python engine/tools.py events --tool SCN-01 --day 11 --window 3
python engine/tools.py investigate L0081
```

`investigate L0081` 응답의 마지막 trace는 `verify_disposition`이어야 한다.

## 이번 버전에서 바뀐 Agent 구조

```text
Lot
 ↓
get_lot_context
 ↓
decompose_cd
 ↓
상황별 tool 선택
 ├─ get_metrology_health
 ├─ get_equipment_events
 └─ compare_chambers
 ↓
verify_disposition
 ↓
Final disposition / abstain
```

현재 planner는 deterministic이다. 이것은 의도적이다. v0.4에서 LLM planner를 붙여도 동일한 tool layer와 verification gate를 재사용한다.
