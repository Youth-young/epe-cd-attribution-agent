CD 이상 원인을 어디서부터 확인해야 할지 빠르게 좁혀보세요

로트를 고르면 상태 → 변화 → 추정 원인 → 권고 조치 → 기술 근거 순서로 보여줍니다. 처음 보는 사람은 결론부터, 엔지니어는 근거까지 내려가며 확인할 수 있습니다.

01
우선 확인할 로트 찾기검색과 필터로 검토가 필요한 로트를 먼저 찾습니다.
02

03
조치와 검증 근거까지 확인추천 조치, Evidence, Investigation Trace, Verification Gate를 이어서 확인합니다.
For beginners

처음 방문했다면

이 웹은 CD 이상이 생겼을 때 노광·식각·계측 중 어느 모듈부터 확인할지 근거를 따라 좁혀주는 분석 도구입니다.

  • 홈에서 전체 흐름을 먼저 파악
  • 검토가 필요한 로트만 빠르게 필터링
  • 모르는 용어는 용어 사전에서 확인
How to read

무엇을 읽게 되나요?

로트를 열면 중요한 판단부터 기술 근거까지 같은 순서로 읽습니다.

  • 상태 — 정상 / 검토 / 조치 필요
  • 변화 — 어떤 지표가 한계를 벗어났는지
  • 원인·조치 — 무엇을 먼저 확인할지
  • 근거 — Evidence / Trace / Gate
For engineers

현업에서는 이렇게 씁니다

단순 이상 탐지를 넘어 원인 후보와 조치 우선순위를 분리해 불필요한 공정 변경을 줄이는 의사결정을 지원합니다.

  • 계측 drift와 실제 공정 이상 분리
  • Track·Reticle·Etch chamber 신호 구분
  • 판정 근거와 검증 게이트를 함께 추적

로트 검토

조치가 필요한 로트를 우선 확인하고, 필요하면 전체 로트로 범위를 넓혀 검토합니다.

예: L0319, SCN-02, RET-B, CH-A
