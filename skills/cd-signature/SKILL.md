# 1단계 · CD 지문 확인

## Trigger
- 특정 로트의 CD 상태를 확인해야 할 때
- CD excursion 조사를 시작할 때 (항상 이 스킬이 먼저다)
- 다른 스킬이 "어떤 성분이 이탈했는가"를 물어올 때

## 책임 범위
**무엇이 어떤 모양으로 어긋났는지까지만** 판정한다.
원인 모듈을 지목하지 않는다. 그것은 `cause-attribution`의 책임이다.

## 절대 규칙
**숫자는 도구만 만든다.** 값을 추정·보간·암산하지 않는다.
도구가 돌려주지 않은 수치는 답변에 쓰지 않는다. 출력이 없으면 "확인 불가"라고 답한다.

## 도구
```bash
python engine/tools.py lot <LOT>          # 공정 경로·설비·dose/focus 컨텍스트
python engine/tools.py decompose <LOT>    # 좌표계별 성분, 관리 한계, 증거 행
python engine/tools.py list --abnormal    # 이상 판정 로트 목록
```

## 판단 기준
성분은 서로 다른 좌표계에 산다. 어느 좌표계에 신호가 실렸는지가 곧 지문이다.

| 성분 | 좌표계 | 읽는 법 |
|---|---|---|
| ADI 스칼라 | 웨이퍼 전체 | 평균이 통째로 이동 |
| ADI 반경 | (r/R)² | 중심-엣지 차이가 벌어짐 |
| 레티클 반복 | field 내 site 고정 | 모든 field에서 동일 위치 반복 |
| ΔCD (etch bias) | ACI − ADI | 식각 이후 가로 폭 변화 |

- 각 성분은 **관리 한계 대비**로만 판정한다. 절대값으로 판단하지 않는다.
- 관리 한계는 기준선 구간에서 산출된 값이다. **임의로 조정하지 않는다.**
- ACI가 측정되지 않은 로트(skip-lot)에서는 **ΔCD를 추정하지 않는다.** "측정 없음"으로 남긴다.

## DoD
- [ ] 모든 감시 성분에 측정값과 관리 한계가 함께 붙어 있다
- [ ] 이탈 성분 목록이 명시되어 있다 (0개면 0개라고 명시)
- [ ] ACI 미측정 로트에서 ΔCD를 추정하지 않았다
- [ ] 원인 모듈을 지목하지 않았다

미충족이면 다음 단계로 넘기지 않고 도구를 다시 호출한다.

## 출력 형식
이탈 성분 목록 / 각 성분의 측정값·한계 / ACI 측정 여부. 그 이상 쓰지 않는다.
